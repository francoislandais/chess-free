# Calme — Échecs

PWA zen pour les parties rapides Lichess.

Application : https://francoislandais.github.io/chess-free/

Le code source complet et les tests sont dans `calme-source.zip`. Les autres fichiers constituent la version statique prête à servir.

Douze tests automatisés passent. La connexion et une partie amicale réelles restent à valider avant un usage classé régulier.

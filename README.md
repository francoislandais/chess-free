# Calme — Échecs

PWA zen pour les parties rapides Lichess.

Application : https://francoislandais.github.io/chess-free/

Le code source complet (commit local b4dc3f8) et les tests sont dans `calme-source.zip`. Les autres fichiers constituent la version statique prête à servir.

Version mobile : échiquier élargi en portrait, commandes dans un menu, pendules latérales en paysage. Correction de la reconnexion inutile après chaque coup. Compilation et 14 tests automatisés réussis. Connexion et partie réelle validées par le propriétaire avant cette mise à jour ; rendu sur téléphone physique à vérifier.
